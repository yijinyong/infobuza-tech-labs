# Practical Examples

## 업무: 장애 대응

```bash
okf-hermes-lab sample-bundle "배포 실패 시 롤백 기준은 무엇입니까?" --max-nodes 2
```

## 업무: 신규 입사자 온보딩

```bash
okf-hermes-lab sample-bundle "신규 입사자의 저장소 권한은 어떻게 신청합니까?" --max-nodes 2
```

## 생활: 정수기 필터 관리

```bash
okf-hermes-lab sample-bundle "정수기 필터 교체 알림이 켜졌습니다" --max-nodes 2
```

출력의 `metadata.concept_ids`로 어떤 문서가 사용됐는지 확인하고, `truncated`가 `true`이면 문자 예산을 검토합니다.
